# TFM_LTSM_Alzheimer
Desarrollo de una red neuronal recurrente (RNN) monocapa en PyTorch para predecir la evolución y modelar patrones en pacientes.  Validación Clínica: Mitigación estricta de data leakage mediante validación cruzada para datos médicos (GroupKFold). Interpretabilidad(XAI): Ingeniería de mecánicas de atribución de características utilizando IG
